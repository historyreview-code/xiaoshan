# 崤山 · 秦晋之役

历史小说。以文赢、秦穆公、孟明视、先轸为线索，重述前628—前627年秦袭郑、殽之战的前因后果，以及此后"三年拜君赐"、封殽尸、霸西戎、秦晋决裂的余波。

据《左传》（僖公三十、三十二、三十三年，文公二、三、六、七年）与《史记·秦本纪》创作。
